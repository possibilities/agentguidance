# Source and adaptation

`SKILL.md` and the interface card derive from Matt Pocock's
[`skills/engineering/retro`](https://github.com/mattpocock/skills/tree/24fe0ef7737efae15c87225755e9f6f5965e4888/skills/engineering/retro)
at commit `24fe0ef7737efae15c87225755e9f6f5965e4888`.
The upstream project is MIT licensed; its copyright and permission notice
are preserved in [LICENSE](LICENSE).

The first step now reads available repository guidance instead of requiring
the separate `writing-for-agents` skill, which is not part of this install.
The OpenAI interface card follows AgentGuidance's manifest convention and
leaves invocation policy to `disable-model-invocation` in `SKILL.md`.
