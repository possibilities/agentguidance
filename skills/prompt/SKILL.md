# Prompt

You are writing from a human to an agent. The deliverable is the prompt
itself: the human's intent, carried in prose that stands alone — the agent
that receives it gets the words and nothing else. Not this conversation,
not the tone of voice, not a chance to ask who meant what.

The ask arrives in many costumes: "help me write a prompt" names it, but
"help me steer that agent", "help me build something", and "I'd like to
collaborate with an agent on…" are the same opening — an idea that has to
leave the conversation as words an agent can run with.

## Size the idea

<!-- fragment: read-the-request.md -->

The classification sets the prompt's shape, not whether to write it. A
question leaves as a question — one clean sentence and whatever context
makes it answerable. Small work rides in a sentence or two plus the one
constraint that is not obvious. Substantial work leaves as a standalone
brief: what to do, where, what done looks like, where to write results.
Right size is the craft: a swollen prompt buries intent, a starved one
makes the agent guess it.

## Close the gaps

Anything the prompt needs that the idea does not carry, go get. Ask the
human one focused question at a time — never a form to fill in. Read the
code the prompt points at; check the glossary so the prompt speaks the
project's canonical terms. Stop gathering the moment the prompt can stand
alone: the goal is the prompt, not a dossier.

## Write human-to-agent

Two motions, both on every draft:

- **Expand** what the human left implicit and the agent cannot infer: the
  goal behind the ask, the constraint that rules out the obvious shortcut,
  what done looks like, where the work lives. A human hears these in the
  room; an agent reads only the words.
- **Compress** everything else. Reduce the wandering thought to the most
  compact, expressive prose that still carries the intent. Every sentence
  earns its place; every vague word is a decision exported to the agent.

State intent, not just instructions — an agent mid-task steers by the goal
when the instructions run out. And leave execution room: over-specifying
mechanics the agent can judge better in place is how prompts go stale
before they are run.

## Steering is the same craft

"Help me steer that agent" opens the same work with a smaller artifact: a
message to an agent already mid-run — a correction, a re-aim, one new
constraint. Write it the same way, expanded where the agent cannot infer
and compressed everywhere else, and let the human deliver it however they
steer that agent today.

## The prompt is the deliverable

The job ends when the prompt exists and the human owns it. Present it
ready to travel — a fenced block that lifts whole. Where it goes —
clipboard, the board, the wiki, straight into a session — is a delivery
instruction that comes after, not part of the craft; take it when it
comes.
