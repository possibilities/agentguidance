# Source and adaptation

This skill's `SKILL.md` and interface card derive from Matt Pocock's
[`skills/engineering/code-review`](https://github.com/mattpocock/skills/tree/d81f3a183412e71a5b1e84ca21bc1a35eea03a60/skills/engineering/code-review)
at commit `d81f3a183412e71a5b1e84ca21bc1a35eea03a60` (v1.3.0).
The upstream project is MIT licensed; its notice is preserved in [LICENSE](LICENSE).

The two-axis method is retained. Fixed-point and spec discovery now use the
repository's own branch, request, and tracker context instead of requiring
Matt Pocock's setup skill or a particular issue-tracker file. Parallel agents
remain optional when unavailable or unnecessary.
